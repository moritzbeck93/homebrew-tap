# Homebrew Tap

Custom Homebrew formulae.

## Install

```bash
brew tap moritzbeck93/tap
```

## Formulae

### slackpit

Slack message testing tool for developers - like Mailpit but for Slack.

```bash
brew install moritzbeck93/tap/slackpit
```

To run as a background service:

```bash
brew services start slackpit
```
